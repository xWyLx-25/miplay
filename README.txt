MiPlay - prototipo web inicial
================================

Cómo abrir:
1. Extrae la carpeta MiPlay.
2. Abre index.html con Chrome, Edge o Firefox.

Incluye:
- Diseño adaptable a móvil y PC.
- Página de inicio y sección de juego destacado.
- Catálogo inicial con SOMBRA marcado como "En desarrollo".
- Filtros por categoría y buscador.
- Ventana de detalles del juego.

Importante:
Esta es una maqueta front-end. Todavía no tiene panel de administración,
base de datos, cuentas, ni alojamiento de archivos para descargas.
Cuando tengas una compilación lista de un juego, se puede añadir su archivo
y conectar el botón de descarga. No se muestra una descarga falsa para SOMBRA.
